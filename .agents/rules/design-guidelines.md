# Design Guidelines & Prohibited Patterns

## Prohibited Patterns (Strict User Requirement)

1. **NO GENERIC ICON-IN-BOX LOGO BADGES**:
   - NEVER place a generic icon inside a small rounded colored rectangle next to the product brand name or header (e.g., an Activity, Heartbeat, Pulse, Flame, Zap, Brain, Sparkle, or Robot icon in a square).
   - The user explicitly prohibited this pattern: *"remove this and remember never give like this to any of my projects in the future also"*.
   - Always use a clean, authentic typographic wordmark alone, or an actual product-specific SVG brand mark if provided by the user.

2. **NO ARTIFICIAL AI METADATA CLICHÉS**:
   - Do not wrap section titles in mini rounded icon containers.
   - Do not use robot/brain icons, glowing borders, or sci-fi labels.
